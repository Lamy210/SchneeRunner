# SchneeRunner v0.1.2

v0.1.2 is the runtime-fix release for the packaged macOS application.

## What changed

v0.1.1 could build successfully and contain a structurally valid application bundle, but the packaged application could terminate during startup while initializing macOS UserNotifications. That failure occurred before the normal menu-bar experience became usable.

v0.1.2 makes system notifications optional startup infrastructure for the intentionally unsigned distribution. The unsigned release bundle explicitly disables the system notification integration while preserving the menu-bar application, bundled four-frame default character, timers, Pomodoro state, reminders, and the rest of the local application lifecycle. A future Developer ID signed/notarized distribution can re-enable the system notification path.

The release pipeline now launch-tests the completed `SchneeRunner.app` through LaunchServices and also launch-tests the application mounted from the generated DMG. Publication is blocked if either packaged application exits during the startup smoke window.

## Distribution status

v0.1.2 remains **unsigned and not notarized**. The runtime startup crash is fixed, but this does not remove macOS Gatekeeper trust warnings for a quarantined download. A downloaded copy may still be reported as damaged or may require an explicit user override. Developer ID signing and Apple notarization are required for the normal frictionless public-distribution trust path.

Do not use v0.1.1 when validating the packaged startup fix; use v0.1.2 or later.
